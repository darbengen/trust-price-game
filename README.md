# 信任的价格 · 3D 第一视角版

## 从 GitHub 获取

3D 模型使用 Git LFS 存储。克隆仓库前请安装 Git LFS 并运行 `git lfs install`，再执行 `git clone`；GitHub 页面上的源码压缩包可能只包含模型指针。

## 打开游戏

双击 `启动游戏.command`，它会在本机启动游戏并用 Chrome 打开。无账号、无后台业务服务、无外部网页依赖；运行时保留终端窗口。关闭窗口即停止本地网页服务。

也可以在本目录运行 `python3 serve.py`。不要直接双击 dist/index.html，浏览器读取 3D 模型需要本地 HTTP 服务。

## 操作

- 小镇：WASD / 方向键移动，Shift 小跑，拖动鼠标转视角，靠近发光门口按 E 进入小屋。四间屋顺序自选。
- 小屋：先与镇民聊几句，选择回复后再开始交易；聊天回复不会改变交易策略或金币。第一位遇到的镇民会在闲聊后介绍投币和吐币规则，之后不再重复。第一视角下点左侧钱堆拿起金币，再点绿色「信任」或红色「欺诈」投币口。点空处放回金币。默认开启快速模式，可直接点投币口；取消「快速」可放慢节奏。键盘 1、2 始终可用。
- 每场 7 轮。投币立刻扣 1，机器两扇窗同时揭晓，然后出币槽按实际结果吐币。被骗时你的出口没有金币。
- 鼠标移动会轻微转头；揭晓、出币、下一轮分别有推近、压低、回正的镜头动作。
- Esc 暂停，可调整声音、画质和金币物理。低画质关闭光晕与景深；关闭物理使用弧线掉落，收益不变。
- 世界：1/3/10 倍、跳到结局；滚轮缩放、拖动旋转。默认把玩家作为第 101 人加入，可在世界开场取消。
- 重新开始清空本次选择；当前不保存进度到磁盘。

## 游戏规则与世界中的你

保持 7 轮的收益、D 的行为、押金规则不变。世界逐圈按编号交易，每对人保留独立历史；生活费按圈初存活者的平均交易净收入乘以 0.8。物理仅用于金币表现，不决定策略、收益或淘汰。

玩家世界策略从四场记录确定：起手选择，以及 CC/CX/XC/XX 四种上一轮结果后的多数选择。没有样本时采用方案参考代码的默认多数规则，平票信任。没有随机行为。

- 关闭「把你也放进世界」：100 人，第 3 圈 A 全部退出，第 21 圈 B/D 退出，第 26 圈稳定。
- 开启：101 人，你在中央。相同的选择产生相同结果；结束圈数受玩家策略影响，不强制写成第 26 圈。
- 一直信任的玩家在第 3 圈退出，当前固定顺序的 101 人世界第 27 圈稳定。
- 32 种玩家策略各强行运行 1500 圈，NPC 最后均为 0/0/25/0；其中仅两种玩家策略存活，与方案一致。

## 源码与文案

- `src/core/`：纯规则、策略、比赛、总榜、玩家策略学习、实时世界与测试。
- `src/scenes/tradeRoom.ts`：第一视角小屋、机器、取币与投币交互、Rapier 金币、镜头与光影。
- `src/scenes/houses.ts`：门口、门标记和完成结果。
- `src/game/`：素材、音效与通用视觉对象。
- `src/main.ts`：场景流程、玩家移动、UI、世界事件回放。
- `src/content.zh.ts`：中文文案，包括可替换的结语和淘汰原因。
- `dist/`：本地可运行构建，包含所需脚本、解码器和素材，无需 CDN。

开发：`npm install` → `npm run dev`。检查：`npm test`、`npm run build`。源代码改动后需重新构建，启动脚本使用 dist。

全部缺失素材回退可用 `?placeholders` 演练，不必真的删除文件。原来的 2D 试玩版保持独立，不受这次改动影响。

## 当前边界

这是可玩的 3D demo。角色已经大幅减面，小屋与机器使用代码搭建，小镇行走范围由原模型地面和建筑碰撞决定；原始村庄模型较大，加载可能比之前稍慢。交易小屋使用用户提供的《Calculated Risk》循环作为背景音乐，默认音量 25%；进屋播放，出屋停止，静音和暂停同步生效。金币等音效仍是合成音。高画质效果与帧率会受设备影响；低画质可关闭光晕、景深，金币物理也可独立关闭。结语和归因文字仍是可替换的占位文案。

### 2D 快速交易与写信人的心声

第一场仍进入 3D 小屋并学习机器规则。此后靠近未完成的镇民按 E，可选择 3D 进屋或 2D 快速；小镇右上角的「以后默认 2D」可跳过后续选择。选择只保存在本次游戏内，刷新即重置。两种模式共享七轮规则和记录；1 / 2 选择信任或欺诈，F 重复上一轮直至结束，按住空格加速。2D 前仍保留与镇民的聊天。

写信人的话不会阻挡操作，结果相关的话只在揭晓后触发；特别重要的事件可以突破普通间隔，因此密集情况下可能超过每场四句。第七轮开始的提示与该轮揭晓后的必说事件也可能先后出现，这是补丁中「最后一轮开始必说」「结果必说」和「每轮只一句」同时成立时无法完全兼容的取舍。结算时会隐藏心声，结算之后继续显示。
